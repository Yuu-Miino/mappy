=====================
Plotting (``plot``)
=====================

.. module:: mappy_ds.plot

.. currentmodule:: mappy_ds.plot

Requires the ``plot`` extra (``pip install "mappy-ds[plot]"``). Matplotlib is
imported lazily, so ``import mappy_ds.plot`` works without it. See
:doc:`/contents/user_guide/plotting`.
